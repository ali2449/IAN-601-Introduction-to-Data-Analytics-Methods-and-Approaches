Big picture

What is Python doing for us?

IAN 601 · Module 1

Python is a tool for writing repeatable instructions. In analytics, those instructions usually follow a simple pattern.

  • Represent: store values in variables.
  • Transform: calculate new values.
  • Communicate: print or format results clearly.
  • Reuse later: apply the same logic again.

Variable naming rules and habits

IAN 601 · Module 1

Good

monthly_sales

Descriptive and readable.

Good

patient_age

Uses lowercase and underscores.

Avoid

ms

Too short for beginners and collaborators.

Invalid

2sales

Variable names cannot start with a number.

Rule of thumb: If another person can guess what the value represents, the name is probably useful.

Section 2 · Data types

Data types tell Python what values mean

IAN 601 · Module 1

The type controls what operations make sense. A number can be averaged. A label should usually stay as text.

int

Whole numbers: counts and units.

float

Decimal numbers: rates and measurements.

str
