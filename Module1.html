🖨️ The print() Function & f‑strings

What is print()?

print() is a built‑in Python function that displays text on the screen. Think of it as a messenger that takes what you give it and shows it to the user.

Example: print("Hello world") → shows Hello world.

You can print numbers, text, variables, or a combination.

What is an f‑string?

An f‑string (formatted string) lets you mix text and variables easily. Put an f before the quotes and use {variable_name} inside.

Analogy: Like a Mad Libs template – you write the story and Python fills in the blanks.

Example: name = "Alice" then print(f"Hello {name}") → Hello Alice.

You can also format numbers: {value:.2f} shows 2 decimal places.

📦 Variables – Storing Information

Variable = labelled box that holds a value. You put data into a box and give it a name. Later, you can open the box and use the data.

✅ Rules: Names can contain letters, numbers, underscores (but cannot start with a number). Choose descriptive names like patient_age instead of x.

🔢 Data Types – Different Kinds of Data

Every value has a type. Python automatically figures out the type.

  • int – whole numbers: age = 25
  • float – decimals: height = 5.9
  • str – text: name = "Alice"
  • bool – True/False: is_healthy = True

Use type() to check a variable's type.

⌨️ Getting User Input

input("Prompt: ") asks the user to type something. It always returns a string. To do math, convert to number using int() or float().

Why conversion? If you add "5" + "10" you get "510" (string concatenation), not 15.

❓ Glossary & FAQ

Glossary

  • print() – function to display output.
  • f-string – formatted string with f"text {variable}".
  • Variable – name that stores a value.
  • int – integer (whole number).
  • float – decimal number.
  • str – string (text).
  • bool – True/False.
  • Type conversion – changing type with int(), float(), str().

FAQ

Q: What is the difference between print("Hello") and print(f"Hello {name}")?
A: The first prints fixed text; the second inserts the value of name into the string.

Q: Why do I get an error when adding a string and a number?
A: Python doesn't know whether to add or concatenate. Use str() to convert number to string, or use an f-string.

Q: How do I show two decimal places?
A: Use {value:.2f} inside an f-string.

Q: What does input() return?
A> Always a string. Convert with int() or float() for numbers.
