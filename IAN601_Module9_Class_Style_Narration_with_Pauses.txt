Slide 1: NumPy for Analytics

Welcome to Module 9. This module focuses on NumPy for analytics.

NumPy helps Python work with numeric data as arrays instead of treating every value one at a time. That is a big shift from earlier modules, where we often used lists and loops to process values manually.

In analytics, we usually work with groups of numbers: scores, sales, visits, measurements, ratings, model inputs, or survey responses. NumPy gives us a way to store those numeric values in a structured form and calculate with them efficiently.

As we move through this module, focus on the main idea: an array lets us think about a whole set of numbers as one object. We can calculate, filter, reshape, and summarize that object in a clear way.

This module also prepares us for Pandas and machine learning libraries, because many of those tools are built on top of NumPy ideas.

Slide 3: Why NumPy instead of regular lists?

Python lists are flexible and useful, but they are not designed mainly for numerical computing.

A list can store different kinds of values at the same time. For example, a list can contain a number, a string, and even another list. That flexibility is useful, but it also means Python treats lists as general containers.

NumPy arrays are different. A NumPy array usually stores values of the same numeric type. Because the structure is more consistent, NumPy can perform numerical operations much more directly.

Think about a list of student scores. If we want to add five points to every score using regular lists, we usually need a loop or a comprehension. With NumPy, we can add five to the entire array.

That is why NumPy is so common in analytics. It helps us write code that is shorter, more readable, and often faster for numeric work.

Slide 5: Lists and arrays behave differently

This slide shows one of the most important differences between Python lists and NumPy arrays.

When we add a Python list to itself, Python joins the list with another copy of the list. So the result becomes a longer list.

But when we add a NumPy array to itself, NumPy adds the matching elements. Ten plus ten becomes twenty. Twenty plus twenty becomes forty. Thirty plus thirty becomes sixty.

The same idea applies when we multiply an array by two. NumPy multiplies each element by two.

Slide 11: Missing numeric values

Real datasets often contain missing values.

In NumPy, a missing numeric value is often represented with np dot nan.

If we calculate a regular mean on an array that contains nan, the result may also be nan. That happens because the missing value affects the calculation.

NumPy provides special functions such as np dot nanmean. This function calculates the mean while ignoring missing values.

In the example, we also use np dot nan_to_num to replace the missing value with the mean.

Be careful with this idea. Filling missing values is a decision. We should not automatically replace missing values without thinking about what it means.

The key point is that missing data should be handled intentionally.

If a z-score is positive, the value is above the mean. If it is negative, the value is below the mean. A value near zero is close to the mean.

Slide 16: Common NumPy mistakes

Most beginner NumPy mistakes come from three areas: shape, axis, and missing values.

If two arrays do not combine correctly, check their shapes. The shape tells you how many values are arranged in each dimension.

If a summary gives an unexpected result, check the axis. Axis zero means down columns in a two-dimensional array. Axis one means across rows.

If a result becomes nan, check whether missing values are present. You may need a nan-aware function such as nanmean.

A good debugging habit is to print the shape and a small sample of the array before doing a larger analysis.

This simple habit can prevent many confusing errors.


Slide 17: NumPy workflow checklist

Here is a practical checklist for NumPy work.

First, create the array. Make sure the data is numeric and organized in the way you expect.

Second, inspect the array. Check the shape, data type, and a small sample of values.

Third, transform the data. You might use vectorized math, Boolean filtering, reshaping, or broadcasting.

Fourth, summarize the result. Calculate totals, averages, variation, or other values that answer your analytical question.

Work in small steps. Run each step before moving on.

This approach makes NumPy easier to learn and makes your analysis easier to trust.
