Why analysts use arrays

NumPy provides the array structure that underpins much of the scientific Python ecosystem. Arrays make numerical operations concise and enable vectorized computation.

Python listgeneral objects
NumPy arraynumeric structure
Vectorized mathwhole-array operations

Learning objectives

  • Create one- and two-dimensional NumPy arrays
  • Inspect array shape and data type
  • Use element-wise arithmetic and broadcasting
  • Apply NumPy mathematical functions
  • Compute descriptive summaries and Boolean filters

Analytics connection

Pandas, SciPy, scikit-learn, and many visualization tools build on NumPy arrays or interact with them directly.

Key takeaways

  • NumPy arrays are optimized for numerical data
  • Vectorized operations replace many explicit loops
  • Broadcasting applies compatible values across arrays
  • NumPy provides fast mathematical and statistical functions
  • Boolean masks filter arrays directly
