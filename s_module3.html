Big picture

Why functions matter in analytics

IAN 601 · Module 3

Without functions, repeated logic is copied again and again. With functions, the logic has one clear home.

  • Less repetition: write the calculation once.
  • Clearer names: describe the purpose of each task.
  • Easier changes: update the function instead of many copies.
  • Better testing: check a small unit of work.

Copied logic

Same formula repeated in many places.

sales - costssales - costssales - costs

Function logic

One clear reusable step.

get_profit(sales, costs)

Inputs to functions

Parameters receive values

IAN 601 · Module 3

A parameter is a name inside the function definition. An argument is the value supplied when the function is called.

def greet(name):name is a parameter.
greet("Avery")"Avery" is an argument.
TermMeaningExample
ParameterA placeholder name inside the function.name in def greet(name)
ArgumentThe actual value passed into the function."Avery" in greet("Avery")
CallThe statement that runs the function.greet("Avery")

Output vs reusable result

return is different from print

IAN 601 · Module 3

print()

Shows a value in the output area. Useful for checking and communication.

return

Sends a value back so another line of code can store it, format it, or use it in another calculation.

Rule of thumb: use return when the result should be reused later.

Variables inside functions are local

IAN 601 · Module 3

A variable created inside a function usually belongs to that function call.

  • Local variable: created inside the function body.
  • Outside code: does not automatically see local names.
  • Return: the clean way to send useful results out.

Self-check

Function design checklist

IAN 601 · Module 3

Name

Does the function name describe the task?

Inputs

Are parameters clear and necessary?

Process

Is the body focused on one job?

Output

Does the function return a reusable value when needed?

Safety

Does it handle predictable problems?

Documentation

Would a future reader understand its purpose?

Good functions are small, named clearly, and easy to reuse.
