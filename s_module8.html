Privacy-minded practice

Responsible example data

IAN 601 · Module 8

Teaching and sample datasets should use fictional or generic values unless real data is clearly permitted.

  • Use fictional names, IDs, emails, and organizations.
  • Remove direct identifiers from examples.
  • Do not publish private data in code outputs.
  • Explain assumptions and limitations clearly.
