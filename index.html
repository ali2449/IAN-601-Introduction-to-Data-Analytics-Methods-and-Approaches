Course Overview

From Python fundamentals to analytical decision-making

IAN 601 introduces the programming and analytical methods students need to move from raw data to defensible, clearly communicated results.

Course Overview

This course is designed to build a strong foundation in programming, data analysis, and analytical problem-solving. It supports learners from a variety of academic and professional backgrounds and introduces technical concepts through practical, hands-on examples.

The course begins with Python programming fundamentals and progressively connects programming concepts to numerical computing, data manipulation, data quality, exploratory data analysis, statistical reasoning, visualization, and introductory machine learning.

No prior programming experience is required for the introductory modules. Learners with previous coding experience can use the foundational material as a structured review before progressing to more advanced analytical tools and techniques.

Python firstBuild programming fluency before adding analytics libraries.

Environment Setup

Prepare your Python workspace

The recommended path is Anaconda because it packages Python, Jupyter, and many common data-science tools into one installation. Students who want more control can use Python and VS Code directly.

Recommended

Option 1 · Anaconda

Use this path if you want the simplest all-in-one setup for the course.

1
Download Anaconda
Choose the installer for Windows, macOS, or Linux.
2
Run the installer
For most students, the standard installation choices are sufficient.
3
Launch Anaconda Navigator
Use Navigator to open JupyterLab or Jupyter Notebook.
4
Verify the environment
Create a notebook and run print("IAN 601 ready").

Manual Setup

Option 2 · Python + VS Code

Use this path if you prefer to manage Python, packages, and your editor separately.

1
Install Python
On Windows, enable the installer option that adds Python to PATH.
2
Install VS Code
Then add Microsoft's official Python extension.
3
Install Jupyter tools
Use a Python environment for the libraries required by the course.
4
Open a notebook
Confirm that Python code executes and output appears correctly.
Python VS Code
Why Jupyter Notebooks? Notebooks let you run code in small cells, write explanatory narrative beside the analysis, and display tables and charts directly below the code that produced them. That combination makes notebooks especially useful for exploratory analytics and reproducible assignments.
