Concept

Why dictionaries and sets matter

IAN 601 · Module 5

Lists are useful when order matters. Dictionaries and sets are useful when meaning or uniqueness matters.

  • Dictionary: stores data as key: value pairs.
  • Set: stores unique values without duplicates.
  • Analytics use: labeled records, category counts, unique IDs, and lookup tables.

Decision guide

Choose the right structure

IAN 601 · Module 5

The best structure depends on how the data will be used.

Use a list

Order matters and duplicates are allowed.

Use a tuple

The record should not change.

Use a dictionary

Values need names or labels.

Use a set

You need unique values or group comparison.
