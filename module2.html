Start Here

From calculations to decisions

Module 1 gave you variables, data types, arithmetic, formatting, and input. Module 2 adds control flow: the rules that decide which code runs and how many times it runs.

Learning objectives

  • Build Boolean conditions with comparison operators.
  • Write if, elif, and else branches.
  • Combine rules with and, or, and not.
  • Use for and while loops appropriately.
  • Control loops with break and continue.
  • Apply control flow to repeated analytical decisions.

Connect to Module 1

  • Variables hold the values being tested.
  • Comparison operators turn values into True/False.
  • Input can drive a decision.
  • Arithmetic results can become thresholds.
  • Indentation now becomes part of program structure.

Business context

Control flow automates rules. A sales system can award a bonus only when a target is met; a health workflow can flag a measurement above a threshold; and a loop can apply the same logic across many observations.

Common beginner mistake: = versus ==

= assigns a value to a variable. == compares two values. A condition normally uses == when checking equality.

Key takeaways

  • Conditions evaluate to True or False.
  • if/elif/else chooses among paths.
  • for repeats across a sequence or known range.
  • while repeats while a condition remains true.
  • break exits and continue skips an iteration.
  • Loops plus conditions are the basis of classification and counting patterns.

FAQ · What is the main difference between for and while?

Use for when iterating over a sequence or a known range. Use while when repetition should continue until a condition changes.

FAQ · Why is indentation important?

Python uses indentation to determine which statements belong to an if, loop, function, or other code block. Incorrect indentation can change the program logic or produce an error.
