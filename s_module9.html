Why NumPy matters

IAN 601 · Module 9

A Python list can store many values. A NumPy array is designed for fast numeric work.

Python listNumPy array
General purposeNumeric computing
Manual loops often usedVectorized operations
Mixed data allowedUsually one dtype
Good for small collectionsGood for arrays and matrices
array + 10Adds 10 to every value at once.
