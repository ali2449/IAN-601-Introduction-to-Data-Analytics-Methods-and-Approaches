Slide 8: Variables can be reassigned

Variables can be reassigned. Python uses the most recent value when later statements refer to that variable.

[pause=1.0]

Slide 9: Assign several values at once

Python can assign several values at once. The order of the values must match the order of the variable names.

[pause=1.0]

Slide 10: Variable naming rules and habits

Use descriptive lowercase names with underscores, avoid reserved keywords, and remember that Python is case sensitive.

[pause=1.0]
