Start Here

Learn one Python idea at a time

This module assumes no prior programming experience. Instead of large code examples, the material is broken into short executable cells that you can read, predict, run, modify, and run again.

Learning objectives

  • Store and update values with variables.
  • Recognize int, float, str, and bool.
  • Perform arithmetic and create derived metrics.
  • Format output with print() and f-strings.
  • Convert text input into useful numeric values.
  • Apply fundamentals to business and healthcare scenarios.

Prerequisites

  • Basic computer use.
  • A modern browser with internet access for the embedded Python runtime.
  • No prior Python experience required.
  • Jupyter/Anaconda remains the primary course workspace for larger assignments.

Business context

Python is useful because it gives analysts a repeatable way to represent data, transform it into metrics, and communicate results. The same fundamentals support profit calculations, patient summaries, scientific measurements, and many other informatics workflows.

Variable naming best practices

  • Prefer descriptive names such as monthly_sales instead of ms.
  • Use lowercase words separated by underscores: patient_age.
  • Start names with a letter or underscore, not a number.
  • Avoid Python keywords such as if, for, and class.

FAQ · What is the difference between return and print()?

print() displays a value for a person to read. return belongs to functions and sends a value back to the calling code; functions are introduced later in the course.

FAQ · Why does input() return a string?

Keyboard and browser input arrives as characters. Your program decides whether those characters should remain text or be converted to a number.
