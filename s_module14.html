Precision, recall, and F1

IAN 601 · Module 14

Precision

Of the cases predicted positive, how many were actually positive?

Recall

Of the actual positive cases, how many did the model find?

F1

A combined measure that balances precision and recall.

Choose metrics based on consequences. Missing a disease case, blocking a legitimate transaction, and sending an unnecessary marketing message have very different costs.

Scikit-learn can calculate several classification metrics at once.

Avoid data leakage

IAN 601 · Module 14

Data leakage occurs when training uses information that would not really be available when the future prediction is made.

  • Including the target itself in the features
  • Using information created after the outcome happened
  • Cleaning or scaling with knowledge from the test set
  • Duplicating the same person or event across train and test
CorrectPast information → model → future prediction
LeakageFuture/outcome information → training features
Leakage can make a weak model look excellent during testing and fail badly in real use.
