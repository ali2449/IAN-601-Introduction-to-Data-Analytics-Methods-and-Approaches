What does “best fit” mean?

IAN 601 · Module 14

For each observation, the model makes a prediction. The difference between the observed value and predicted value is a residual.

residual = actual − predictedsmaller overall error → better-fitting line

Many machine learning algorithms choose parameters by minimizing some form of loss or error.

Accuracy, precision, recall, and F1

IAN 601 · Module 14

Accuracy

What fraction of all predictions were correct?

Precision

When the model predicted positive, how often was it right?

Recall

Of all actual positives, how many did the model find?

F1

Balances precision and recall in one score.

Metric choice depends on consequences. Missing a serious case can matter more than producing an extra false alarm—or the reverse, depending on the application.

Machine Learning & External Data · A Bridge to MLIAN 601 · Module 14 · Slide 27
Do not accidentally let the model see the future or the answer

Avoid data leakage

IAN 601 · Module 14

Leakage can make a weak model look excellent during evaluation and then fail in real use.

  • Target included in features
  • Future information used to predict the past
  • Preprocessing fitted using test data
  • Duplicate people or events split across train and test
Correct workflowPast information → model → future outcome
Leaky workflowFuture/outcome information → training features
Ask this question for every feature: Would I truly know this value at the moment the prediction is needed?
