Concept

Why sequences matter in analytics

IAN 601 · Module 4

In analytics, one observation is rarely enough. Lists and tuples let us group related values and work with them as one object.

  • List: an ordered collection that can be changed.
  • Tuple: an ordered collection that should stay fixed.
  • Index: a position number used to access a value.

Decision guide

Choose the right sequence

IAN 601 · Module 4

Use a list when...

  • Values may change.
  • You need to append or remove items.
  • You need to sort, filter, or build a collection over time.

Use a tuple when...

  • Values should stay fixed.
  • The values form one record.
  • You want to return multiple results from a function.
Simple rule: lists are flexible collections; tuples are fixed records.
