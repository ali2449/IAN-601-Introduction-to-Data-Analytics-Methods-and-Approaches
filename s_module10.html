Core structures

Series and DataFrame

IAN 601 · Module 10
Series

One labeled dimension

Useful for one column such as amount, channel, or date.

orders["amount"]
DataFrame

Rows + columns

Each column has a name and dtype. Each row has an index.

orders[["channel", "amount"]]
Beginner habit: Before using a method, ask whether you are working with a Series or a DataFrame. That explains many confusing errors.

Job-ready Pandas checklist

IAN 601 · Module 10

Core table work

DataFrame, Series, read_csv, head, shape, dtypes, info

Selection

columns, loc, iloc, Boolean masks, query, sort_values

Cleaning

isna, fillna, dropna, duplicated, drop_duplicates, to_numeric, to_datetime, str

Analysis

describe, value_counts, groupby, agg, pivot_table, crosstab

Combining

merge, concat, join validation, row-count checks

Professional habits

vectorize when possible, verify assumptions, document decisions, know when to use SQL/Spark instead
