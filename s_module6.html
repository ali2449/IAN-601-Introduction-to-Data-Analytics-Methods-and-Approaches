Concept

Why organize code?

IAN 601 · Module 6

As programs get longer, organization becomes part of the solution.

  • Imports reuse code that already exists.
  • Packages group many modules together.
  • Classes group related data and actions.
  • Well-organized code is easier to test, share, and update.

OOP concept

What is a class?

IAN 601 · Module 6

A class is a blueprint. An object is one item created from that blueprint.

  • Attributes store information.
  • Methods perform actions.
  • The word self means this specific object.
